# Mods de Claude Code

| Mod | Qué hace |
| --- | --- |
| [session-meter](plugins/session-meter) | Barra de progreso arriba del prompt que sigue la lista de tareas de Claude, y un panel (`/session-meter`) con costo, tokens, contexto y tiempo de la sesión y de cada subagente. |

Instalación, en una sesión de Claude Code en la terminal:

```
/plugin install session-meter --marketplace randy-kauffman/TestProject
```
